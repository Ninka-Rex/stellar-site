Finally, a stellar download manager!

Stellar is a download manager for Windows and Linux. It has a powerful download engine built to recover from disruptions, handle large downloads with many connections at once, support torrents, and download from sites like YouTube and Twitter.

Powerful download engine

Built for large downloads and long-running transfers.

Stellar keeps multiple connections busy at once, which helps large files finish faster than a single-threaded transfer.

If a connection drops, Stellar retries the broken segment instead of starting the whole file over, then recombines everything when the transfer finishes.

Torrent support

Full torrent tools live in the same app.

That means you can manage direct downloads and torrents side by side instead of juggling a second client.

Queue torrents, bind traffic to an adapter, ban peers by client or country, and inspect live piece and swarm maps while the transfer runs.

Download from sites like YouTube and Twitter

Media downloads stay inside Stellar instead of bouncing through extra tools.

Pick formats before the transfer starts, keep the workflow in one place, and save the result with the rest of your downloads.

Stellar can also pass cookies through for authenticated, logged-in downloads when a site expects your session context.

Modern, cross platform UI

One interface across desktop platforms.

The app stays focused on practical controls instead of burying everything behind extra layers and popovers.

Downloads, queues, categories, torrent tools, and media tools all stay together in one window, on both Windows and Linux.

Built-in torrent search

Search is built into the app.

That means you can search, inspect results, and start torrenting without breaking out into a browser first.

Stellar uses qBittorrent-compatible Python plugins and keeps results inside the main window so they can go straight into the torrent workflow.

Intercepts browser downloads

Browser handoff stays intact.

Stellar catches downloads before the browser takes over, so you do not have to copy links around by hand.

It passes the URL, filename, referrer, and cookie context into Stellar, which helps with sites that depend on the original request.
